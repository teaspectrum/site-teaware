ABOUT THE OPEN PROJECT

One leaf,
a world to discover.

Chapu is an open bilingual tea knowledge project. One public Markdown content repository, organised into tea, teaware and culture sections, connects five themed sites so tea, objects, culture, teahouses and routes share one traceable structure.

Technical architecture

The five sites use Astro 7.4.4 static generation and TypeScript with shared content-core, ui, brand and build-tools packages. Pages are complete HTML at build time; theme, language, filtering and search load a small amount of vanilla JavaScript only when needed. Search uses a static build-time index, and route maps and elevation use inline SVG without third-party map tiles.

This structure suits GitHub Pages: no server runtime, database or persistent API. The sites can deploy as project pages in five repositories or bind chapu.org and four subdomains. Legacy query-string URLs are no longer supported: old links return 404, and the new site publishes only new paths.

Content tiers

Core entries are editorially shaped, more complete and carry at least one traceable source. Reference entries normally remain in the archive; they enter the public site one by one only after sources and a complete English translation are added. The public site publishes only entries whose Chinese and English versions are both reviewed; a core badge alone does not guarantee publication.

What is complete, and what is not

Structure, routing, shared UI, 2342 language-level entries, the bilingual publication gate, traceable-source display, 479 licensed image files covering 610 public entries, search, route stations and maps are implemented. The public surface currently has 610 topics and 1220 bilingual detail pages; another 1122 language-level entries remain in the archive and do not enter the public site.

This is not a claim that all content has been reviewed: the public site covers reviewed core entries only; the rest will be released in batches after translation and source review.
