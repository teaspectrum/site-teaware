茶谱是一个开放的双语茶知识项目。一个公开 Markdown 内容仓库，按茶叶、茶器、茶文化三个内容分区组织，连接五个主题网站，让茶叶、器物、文化、茶馆与茶路共用一套可追溯的知识结构。

技术架构

五个网站使用 Astro 7.4.4 静态生成与 TypeScript，共享 content-core、ui、brand、build-tools。页面在构建时输出完整 HTML；主题、语言、筛选与搜索只在需要时加载少量原生 JavaScript。搜索使用构建时生成的静态索引，路线地图与高程使用内联 SVG，不依赖第三方地图瓦片。

这套结构适合 GitHub Pages：没有服务器运行时、没有数据库、没有需要常驻的 API。站点可以部署为五个独立仓库的项目页，也可以绑定 chapu.org 与四个子域名。旧站查询参数地址不再兼容，旧链接直接返回 404；新站只按新路径发布。

内容分级

核心条目是编辑策划、结构较完整、至少有一条可定位来源的内容；参考条目默认留在资料库，只有补齐来源并完成英文全译后才逐条进入公开站。公开站只发布中英双语都已复核的条目，核心徽章不等于自动发布。

现在的完成边界

结构、路由、五站共享 UI、2338 条语言级内容、双语公开门槛、可核查来源展示、301 个授权图片文件（覆盖 573 个公开条目）、搜索、路线节点与地图均已实现。当前公开面为 591 个主题、1182 个中英详情页；另有 1156 条语言级内容留在资料库，不进入公开站。

这不是“内容已经全部审核”的声明：公开站只覆盖已复核的核心，剩余条目需按批次补译、复核来源后再逐批放出。
